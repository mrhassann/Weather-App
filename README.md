# ☀️ سكاي كاست (Skycast) — موقع الطقس المباشر

موقع طقس حديث ولحظي يعتمد على **Open-Meteo** (مجاني وبدون مفتاح API)، ويعمل كتطبيق **PWA** يمكن تثبيته على الهاتف.

## ✨ المميزات

- الطقس الحالي: الحرارة، المحسوسة، الحالة مع أيقونة متحركة، الرطوبة، الرياح واتجاهها، مؤشر UV، الضغط، مدى الرؤية، الشروق والغروب.
- توقعات الـ 24 ساعة القادمة (شريط أفقي + رسم بياني لدرجة الحرارة).
- توقعات 7 أيام (العظمى/الصغرى، الحالة، احتمال المطر).
- جودة الهواء (US AQI + الملوثات).
- بحث عن المدن مع اقتراحات تلقائية + قائمة مفضلة محفوظة في المتصفح.
- التبديل بين °C/°F و كم/س / ميل/س، وبين العربية (RTL) والإنجليزية.
- خلفية متحركة تتغير حسب الطقس والليل والنهار، ووضع داكن/فاتح.
- تحديث تلقائي كل 5 دقائق بدون إعادة تحميل الصفحة، مع عدّاد "آخر تحديث" وساعة حية بتوقيت المدينة.
- يعمل بدون إنترنت بعرض آخر بيانات محفوظة، مع رسائل خطأ واضحة.

## 🛠️ لماذا HTML + CSS + JavaScript بدون React؟

المشروع صفحة واحدة بحالة بسيطة، فلا يحتاج إطار عمل. النتيجة:
- **لا توجد خطوة build** ولا مكتبات لتثبيتها — الملفات تُرفع كما هي.
- **حجم صغير جدًا** وتحميل سريع على الهاتف.
- **PWA أبسط**: الـ Service Worker يخزّن الملفات نفسها مباشرة.

## 🚀 التشغيل محليًا

تحتاج فقط إلى [Node.js](https://nodejs.org) (بدون `npm install`):

```bash
cd weather-app
npm start
```

ثم افتح: **http://localhost:5500**

> لتغيير المنفذ: `node server.js 8080`
>
> ملاحظة: لا تفتح `index.html` بالنقر المزدوج، لأن الـ Service Worker والـ ES Modules تحتاج خادمًا (http).
> بعد تعديل الملفات، إذا لم تظهر التغييرات أعد تحميل الصفحة مرتين (أو غيّر `VERSION` في `sw.js`).

## 🌍 النشر مجانًا

### الخيار 1: Netlify (الأسهل)
1. ادخل إلى [app.netlify.com/drop](https://app.netlify.com/drop).
2. اسحب مجلد **`weather-app`** وأفلته في الصفحة.
3. سيعطيك رابطًا مباشرًا مثل `https://xxx.netlify.app` ✅

أو عن طريق GitHub: ارفع المشروع ← **Add new site ← Import from Git** ← اختر المستودع، واجعل **Base directory** = `weather-app` واترك أمر البناء فارغًا. (ملف `netlify.toml` جاهز.)

### الخيار 2: Vercel
**من الموقع:** ارفع المشروع إلى GitHub ← في [vercel.com/new](https://vercel.com/new) اختر المستودع ← اجعل **Root Directory** = `weather-app` ← **Framework Preset: Other** ← اترك أمر البناء فارغًا ← **Deploy**.

**من سطر الأوامر:**
```bash
npm i -g vercel
cd weather-app
vercel          # للمعاينة
vercel --prod   # للنشر النهائي
```

> الموقع يجب أن يعمل عبر **HTTPS** حتى يعمل تحديد الموقع والتثبيت كتطبيق — وNetlify وVercel يوفرانه تلقائيًا.

## 📱 التثبيت على الهاتف
- **أندرويد (Chrome):** افتح الموقع ← القائمة ⋮ ← **تثبيت التطبيق** (أو زر "ثبّت التطبيق" أسفل الصفحة).
- **آيفون (Safari):** زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

## 📁 هيكل المشروع

```
weather-app/
├── index.html            الصفحة الرئيسية
├── css/styles.css        التصميم (Mobile-first + RTL + الوضع الداكن + الحركات)
├── js/app.js             الحالة، جلب البيانات، العرض، الأحداث
├── js/api.js             استدعاءات Open-Meteo (الطقس، جودة الهواء، البحث)
├── js/i18n.js            النصوص العربية والإنجليزية
├── js/weather.js         أكواد الطقس + الأيقونات المتحركة (SVG)
├── js/sky.js             الخلفية المتحركة (مطر، ثلج، نجوم، سحب، برق)
├── js/chart.js           الرسم البياني لدرجة الحرارة
├── sw.js                 Service Worker (العمل بدون إنترنت)
├── manifest.webmanifest  إعدادات الـ PWA
├── icons/                أيقونات التطبيق
└── server.js             خادم محلي بسيط للتطوير
```
